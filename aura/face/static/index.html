How to read this

Each row is one invisible radio path through the room — AP rows come from surrounding WiFi networks, LINK is the board's own connection (the sharpest sensor). Time flows left to right (last ~60 s). Dark = path calm; bright = a body is bending that path. A person walking paints bright vertical bands across several rows at once; an empty room stays dark; a single flickering row alone is just radio noise.
