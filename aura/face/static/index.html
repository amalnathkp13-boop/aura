RF disturbance events (CUSUM change-points)
    How to read this

    Every WiFi path the board can hear acts as one "receiver". Each receiver card shows its live signal, how disturbed it is (variance vs. its calibrated threshold — yellow tick), the human-motion band energy, and its vote. The fused state needs a weighted majority — one noisy receiver cannot fake a person. The room view is a top-down sketch of those radio paths: the lens between board and phone is the main sensing link, the thin lines are surrounding-network paths. Each path brightens as its own live disturbance rises, rings fire on real change-point detections, and the presence marker drifts toward the centre of whichever paths are disturbed — its size tracks activity, it pulses with motion. Positions are derived from per-path signal ratios, not measured: RSSI physics cannot localise a person, which is why this is imaging-style, not imaging.

    RF waterfall

    calmdisturbed
    How to read this

    Each row is one invisible radio path through the room — AP rows come from surrounding WiFi networks, LINK is the board's own connection (the sharpest sensor). Time flows left to right (last ~60 s). Dark = path calm; bright = a body is bending that path. A person walking paints bright vertical bands across several rows at once; an empty room stays dark; a single flickering row alone is just radio noise.

    Motion spectrogram

    calmdisturbed
    How to read this

    This is the room's motion rhythm. Y = how fast something repeats (Hz), X = time. Each band's color is scaled to its own recent history, so it lights up on a CHANGE — a person walking bursts the 0.5–2 Hz band, breathing bursts near the bottom, a ceiling fan draws one thin steady line, an empty room stays dark.
